## Review remediation

- Buddy Auto Lite 在处理 Codex feedback 前，先按违反的不变量或共同根因聚类 findings。
- 同轮多个同源 finding，或相同失败类别再次出现时，禁止继续逐点增加条件分支；代理必须重新推导不变量，并审计完整状态机、权威边界、读写和校验路径。
- 根因修复覆盖完整影响面，并为已报告触发场景及同类 sibling 路径提供回归证据；需要扩大 OpenSpec 范围、公共 API 或数据模型时停止并请求授权。
